Proyecto Verano (Web Corporativa)

Web Estática, Integración de Formularios

Demo Código

Tecnologías: HTML5, CSS3, JavaScript, Bootstrap, Google Forms.

Situación

La empresa requería una presencia digital profesional y, más importante, un sistema eficiente para capturar solicitudes de cotización, que antes se manejaban por vías desorganizadas.

Tarea

Mi objetivo fue diseñar e implementar una web corporativa informativa, integrando un flujo de contacto automatizado para mejorar la gestión de leads y la primera respuesta al cliente.

Acción

Parking Lot Web (Gestión de Estacionamiento)

Python (Flask), MySQL, Full Stack

Demo Código

Tecnologías: Python (Flask), MySQL, HTML, CSS, JavaScript.

Situación

Se necesitaba un sistema digital para reemplazar la gestión manual de un estacionamiento, buscando eliminar errores humanos en el cálculo de tarifas y mejorar el control de inventario de plazas.

Tarea

Mi principal tarea fue el desarrollo del módulo de lógica de negocio (backend) para el registro de entrada/salida de vehículos, cálculo de tarifas basado en tiempo y gestión de plazas ocupadas.

Acción

Construí el backend utilizando **Python con el microframework Flask**, diseñando un esquema de base de datos en **MySQL** para el almacenamiento seguro de transacciones y datos de clientes. Implementé validaciones estrictas para asegurar la integridad de los datos de cobro.

Resultado

La aplicación automatizó el control de tiempo y cobro, **eliminando los errores de cálculo** y proporcionando un registro histórico completo. La implementación Full Stack resultó en un sistema operativo y escalable para la administración del estacionamiento.
